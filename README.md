# Spritepocalypse

A tower defence where any of 1.4 million pixel sprites can be a tower. Draw a maze, type a word, get a tower.

Play it: https://krimsonaer.github.io/spritepocalypse/

Sprites are from the Pixel Art Atlas dataset by Angais (CC0):
https://huggingface.co/datasets/Angais/pixel-art-atlas-1.4m
